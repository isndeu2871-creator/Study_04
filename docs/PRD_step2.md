# PRD 2단계 — 식재료로 레시피 추천

## 목표

1단계에서 얻은 식재료 목록을 텍스트 모델에 보내 레시피를 추천받는다.

## 쓰는 모델

| 차례 | 모델 |
| --- | --- |
| 1 | `nvidia/nemotron-3-super-120b-a12b:free` (수업 선정) |
| 예비 1 | `minimax/minimax-m3.1-flash:free` |
| 예비 2 | `openrouter/free` |
| 예비 3 | `cohere/north-mini-code:free` |

## 기능

### F1. 재료 보여 주기

제목 바로 밑에 1단계에서 확정한 재료를 회색 타원으로 한 줄에 늘어놓는다.

### F2. 조건 고르기

`레시피 생성하기` 버튼 위에 드롭다운 네 개를 둔다.

| 조건 | 값 |
| --- | --- |
| 종류 | 한식, 양식, 중식, 일식 |
| 난이도 | 초급, 중급, 고급 |
| 조리 시간 | 15분 이내, 30분 이내, 30분 이상 |
| 인원 | 1인분, 2인분, 3인분, 4인분 |

3단계를 만든 뒤에는 프로필에 저장한 값을 기본값으로 띄우되 고칠 수 있게 한다.

### F3. 레시피 만들기

재료와 조건을 텍스트 모델에 보내 레시피 3개를 JSON 으로 받는다.

```json
{"recipes": [{
  "title": "시금치 달걀볶음",
  "cuisine": "한식",
  "difficulty": "초급",
  "time_minutes": 15,
  "servings": 2,
  "used_ingredients": ["달걀", "시금치"],
  "missing_ingredients": ["참기름"],
  "steps": ["...", "..."]
}]}
```

### F4. 화면

- 레시피를 카드 세 개로 늘어놓는다
- `자세히 보기` 버튼의 세로 위치를 카드마다 같게 맞춘다
- `부족한 재료` 를 따로 표시한다
- 1단계에서 `레시피 추천받기` 를 누르고 넘어오면 버튼을 다시 누르지 않아도 바로 만든다

### F5. 시도와 전환

1단계 F4 와 같다. 실패하면 1단계 F6 처럼 정직하게 알린다.

### F6. 단계 이동

언제든 이전 단계로 돌아갈 수 있게 한다.

## 받아들이는 조건

- [ ] 재료와 조건이 레시피에 반영된다
- [ ] 레시피 3개가 카드로 나온다
- [ ] 부족한 재료가 표시된다
- [ ] 선정 모델이 막히면 예비 모델로 넘어간다
- [ ] 실패하면 실패했다고 화면에 뜬다
